# Zazu's Coffee

A responsive, multi-page website for **Zazu's Coffee** — a fictional Nairobi-based coffee shop.

Built as a Web Application Development course project at **Strathmore University**.

---

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero banner, featured drinks, welcome section |
| Menu | `pages/menu.html` | Full menu with category filter (JS) |
| About | `pages/about.html` | Our story, values, and team |
| Gallery | `pages/gallery.html` | Photo gallery of café and drinks |
| Blog | `pages/blog.html` | Coffee articles and Nairobi café culture |
| Locations | `pages/locations.html` | Branch info, hours, and map |
| Contact | `pages/contact.html` | Contact form with JS validation |

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Git & GitHub

---

## Interactive Features

1. **Menu category filter** — filter items by Hot, Cold, or Food
2. **Contact form validation** — real-time JS validation before submission
